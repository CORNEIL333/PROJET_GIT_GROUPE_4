❓ Questions fréquentes

Tout ce que tu dois savoir sur la plateforme.

Comment créer mon premier dépôt ? +
Connecte-toi, va dans "Mes Dépôts" et clique sur "Nouveau dépôt". Donne-lui un nom et une description, puis clique sur "Créer".
J'ai oublié mon mot de passe, que faire ? +
Contacte ton administrateur universitaire avec ton email et ton matricule. Il pourra réinitialiser ton mot de passe.
Comment soumettre un TP ? +
Fais git add, git commit et git push sur ta branche, puis ouvre une Pull Request vers la branche principale du dépôt cours.
Quelle est la différence entre commit et push ? +
Un commit sauvegarde tes changements localement sur ton ordinateur. Un push envoie ces commits vers GitHub pour que tout le monde puisse les voir.
Comment rejoindre le dépôt de mon groupe ? +
Demande à ton chef de groupe ou à l'enseignant de t'ajouter comme collaborateur. Tu recevras un email d'invitation à accepter.
