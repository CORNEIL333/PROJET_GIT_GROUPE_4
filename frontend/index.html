🗺️ Comment ça marche ?

En 4 étapes simples, commence à collaborer sur la plateforme.

1

Crée ton compte

Inscris-toi avec ton email universitaire et choisis ton rôle (étudiant, enseignant).

2

Clone un dépôt

Récupère le dépôt de ton cours avec git clone sur ton ordinateur.

3

Travaille & commit

Modifie tes fichiers, sauvegarde avec git commit à chaque avancée.

4

Push & collabore

Envoie ton travail avec git push et ouvre une Pull Request pour révision.

👥 Qui peut utiliser la plateforme ?

Trois types d'utilisateurs, chacun avec ses droits et responsabilités.

Étudiant

Accède à tes dépôts de cours, soumet tes TPs et collabore avec ton groupe de projet.

Enseignant

Crée des dépôts de cours, distribue les sujets et évalue les travaux via les issues.

Administrateur

Gère les comptes, les permissions, les sauvegardes et la configuration globale du serveur.

Délégué de groupe

Coordonne le dépôt de son groupe, valide les merge requests et gère les conflits.
