🗺️ Comment ça marche ?

En 4 étapes simples, commence à collaborer sur la plateforme.

1

Crée ton compte

Étudiant ? Inscris-toi librement. Enseignant ? L'admin te donne un code unique.

2

Clone un dépôt

Récupère le dépôt de ton cours avec git clone sur ton ordinateur.

3

Travaille & commit

Modifie tes fichiers, sauvegarde avec git commit à chaque avancée.

4

Push & collabore

Envoie ton travail avec git push et ouvre une Pull Request pour révision.

👥 Qui peut utiliser la plateforme ?

Trois types d'utilisateurs, chacun avec ses droits.

Étudiant

S'inscrit librement. Accède à ses dépôts de cours, soumet ses TPs et collabore avec son groupe.

Enseignant

Rejoint sur invitation de l'admin avec un code unique. Crée des cours et évalue les travaux.

Administrateur

Gère les comptes, génère les codes d'invitation enseignants et supervise la plateforme.
