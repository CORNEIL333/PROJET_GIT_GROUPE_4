# 🖥️ Guide Frontend — GitUniversitaire

## Structure des fichiers
- `index.html` : Page principale
- `404.html` : Page d'erreur
- `style.css` : Styles globaux
- `app.js` : Logique JavaScript

## Technologies utilisées
- HTML5 / CSS3 / JavaScript pur
- Font Awesome 6.4
- Google Fonts — Inter
- IntersectionObserver API

## Composants principaux
### Navbar
Navigation sticky en haut de page.
### Modal de connexion
Fenêtre avec 3 rôles : étudiant, enseignant, administrateur.
### Compteurs animés
4 compteurs qui s'animent au scroll.
### Toasts
Messages de notification en bas de l'écran.
